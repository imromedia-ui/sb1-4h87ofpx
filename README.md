# Kalon Primary Care and Wellness

A modern, responsive website for Kalon Primary Care and Wellness in Ormond Beach, FL.

🌐 **Live Site**: https://imromedia-ui.github.io/sb1-4h87ofpx/

## 🌟 Features

- **Responsive Design** - Optimized for all devices (mobile, tablet, desktop)
- **Modern Healthcare UI** - Clean, professional design with healthcare focus
- **Contact Forms** - Easy appointment booking and contact functionality
- **Service Information** - Detailed information about medical services
- **Team Profiles** - Meet the healthcare professionals
- **Policies Pages** - Terms, privacy, and cancellation policies
- **Fast Performance** - Built with Vite and React for optimal speed

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Design System

- **Colors**: Sage green, warm whites, charcoal grays
- **Typography**: Playfair Display (serif) + Inter (sans-serif)
- **Framework**: Tailwind CSS for styling
- **Icons**: Lucide React for consistent iconography

## 🌐 Deployment

This project is automatically deployed to GitHub Pages using GitHub Actions.

### Manual Deployment
1. Build the project: `npm run build`
2. The `dist` folder contains the production files
3. Push to the `main` branch to trigger automatic deployment

### GitHub Pages Setup
1. Repository Settings → Pages
2. Source: "GitHub Actions"
3. The workflow will handle the rest automatically
